Oblivion - a Mod Organizer 2 theme - version 1.0.0

The look of Apocrypha Menu Framework for Oblivion Remastered's "Oblivion" theme in Mod Organizer 2: parchment panels,
brown ink text and lines, a brass accent, and an embroidered map's edge in gold and brown - a couched gold cord, a
compass star at each corner, a brown running stitch - round the mod list, the plugin list, the log, menus and tooltips.

INSTALL
  1. Extract this archive into your Mod Organizer 2 folder (the folder with ModOrganizer.exe),
     so that stylesheets\Oblivion.qss and the stylesheets\Oblivion\ folder land in MO2's own stylesheets folder.
  2. In MO2: Settings > General > Style > Oblivion.
  3. Restart MO2 once so the toolbar picks up the icons.

NOTES
  * Separators are the mod list's rows that have mods under them (MO2's collapsible separators,
    on by default). An empty separator shows in the mod-row colour.
  * The theme's separator colour is drawn over a colour picked for a separator in MO2.
  * MO2's conflict highlight on mods stays visible.
